PRÁCTICA 01 · REALIDAD VIRTUAL

Primeros pasos en Unity & VR

En esta práctica nos familiarizamos con el entorno de desarrollo de Unity mediante la creación de un escenario tridimensional y comenzamos el desarrollo de nuestro proyecto final de realidad virtual.

SOFTWARE Unity · Blender
ÁREA Realidad Virtual
ESTADO ● Completada
01

INTRODUCCIÓN

Objetivo de la práctica

El objetivo principal fue conocer las herramientas básicas de Unity para la construcción y organización de entornos tridimensionales orientados a experiencias de realidad virtual.

Durante la práctica aprendimos a manipular objetos, modificar sus transformaciones y establecer relaciones jerárquicas entre ellos. Adicionalmente, realizamos un primer avance del proyecto final mediante el desarrollo inicial de un maniquí de RCP.

02

ACTIVIDAD 01

Creación de un parque en Unity

UNITY · ENTORNO 3D

Familiarización con el entorno

La primera actividad consistió en crear un parque utilizando distintos elementos tridimensionales. Esto nos permitió conocer la interfaz de Unity y aprender a trabajar con la posición, rotación y escala de los objetos dentro de una escena.

También trabajamos con el sistema de jerarquías padre-hijo, el cual permite establecer relaciones entre diferentes objetos para controlar de manera correcta sus transformaciones.

✦

Ejemplo: rueda de la fortuna

La estructura principal permanece fija, mientras que únicamente la rueda realiza la rotación. Las cabinas están organizadas dentro de la jerarquía para acompañar correctamente el movimiento de la rueda.

PROTOTIPO INICIAL

Modelado mediante código

Para esta primera versión se desarrolló el modelo del maniquí en Blender utilizando un script. El cuerpo fue generado a partir de distintas figuras geométricas que posteriormente fueron escaladas, rotadas y posicionadas para aproximarse a la anatomía de un maniquí de RCP.

Este modelo representa el punto de partida del proyecto. Conforme avance el desarrollo se buscará mejorar su apariencia, anatomía e interacción para integrarlo en una experiencia inmersiva de realidad virtual.
